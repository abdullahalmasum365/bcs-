Module 1: The 3-State Spoken Tense Engine
Tense Architecture

বাংলা ভাষাভাষী শিক্ষকদের স্পোকেন ইংলিশে ফ্রিজ (freeze) হয়ে যাওয়ার প্রধান কারণ হলো: কথা বলার মুহূর্তে ব্রেইনে ১২টি টেন্সের ব্যাকরণ সূত্র একসাথে চিন্তা করা। কিন্তু বাস্তব জীবনে নেটিভ স্পিকার ও প্রফেশনালরা তাদের বক্তব্যের ৯০% সময় মাত্র ৩টি স্টেটে কথা বলেন।

১.১ স্টেটগুলোর পুঙ্খানুপুঙ্খ মেকানিক্স:

স্টেট (State) কখন ব্যবহার করবেন? স্ট্রাকচার ফর্মুলা বাস্তব ক্লাসরুম উদাহরণ
State 1: Present (V1) আপনার নিয়মিত অভ্যাস, পেশাগত দায়িত্ব, সফটওয়্যারের ফ্যাক্ট। Subject + V1 (s/es) • "Computers follow instructions."
• "A green flag triggers the loop."
State 2: Past (V2) অতীতের যেকোনো গল্প, গতকালের ক্লাস বা আগের কোনো ফিক্স। Subject + V2 • "The student faced a bug."
• "I helped him fix the code."
State 3: Future পরবর্তী ক্লাসের পরিকল্পনা বা পরবর্তী পদক্ষেপ। Subject + will + V1 • "Next week, we will build an animation."
• "I will demonstrate the loop."
State 4: Live Action স্ক্রিনের দিকে তাকিয়ে এই মুহূর্তে যা ঘটছে। am/is/are + V-ing • "The sprite is moving right now."
• "They are coding games."
⚠️ The Golden DID Rule (অতীতের সবচেয়ে বড় ভুল যেখানে হয়):
অতীতে কোনো প্রশ্ন করতে বা 'না' (Negative) বলতে সেন্টেন্সে যখনই DID আসে, মূল ভার্ব সবসময় তার আদি রূপ V1 (Base Form)-এ ফিরে যায়!
❌ ভুল: "The cat did not moved." | "Did you saw the bug?"
✅ সঠিক: "The cat did not move." | "Did you see the bug?"
Module 2: Demystifying V3 & Past Participle
Finished State & Bodyguards

শিক্ষার্থীদের সবচেয়ে বড় কনফিউশন তৈরি করে "Past Participle" (V3) শব্দটি। নামের সাথে "Past" থাকলেও এটি আসলে বর্তমান কালেও হরহামেশা ব্যবহৃত হয়। কম্পিউটার সায়েন্সের ভাষায় V3 হলো একটি `COMPLETED` Status Flag!

২.১ The V3 Bodyguard Rule (বডিগার্ড রুল)

🛡️ V3 কখনো একা হাঁটতে পারে না!

ইংরেজি ভাষায় $V_1$ একা বসে, $V_2$ একা বসে। কিন্তু $V_3$ এতোই দুর্বল যে সে বডিগার্ড ছাড়া বাক্যেই বসতে পারে না! তার বডিগার্ড কারা? have / has / had অথবা am / is / are / was / were।
• ❌ "I done the project." (বডিগার্ড নেই—ভুল!)
• ✅ "I have done the project." (বডিগার্ড 'have' আছে—সঠিক!)

২.২ V3-এর দ্বিতীয় রূপ: Adjective (কোনো জিনিসের অবস্থা)

V3 শুধু প্রেজেন্ট পারফেক্টেই লাগে না, কোনো জিনিসের ফিনিশড অবস্থা বোঝাতে চমৎকার কাজ করে:

মূল ভার্ব (V1) সম্পন্ন হওয়া অবস্থা (V3) বাস্তব প্রয়োগ ও অর্থ
Break (ভাঙা) Broken "This is a broken mouse." (ভাঙা মাউস)
Connect (সংযুক্ত করা) Connected "The laptop is connected to Wi-Fi." (কানেক্টেড অবস্থা)
Close (বন্ধ করা) Closed "The tab is closed." (ট্যাবটি বন্ধ অবস্থায় আছে)
Write (লেখা) Written "The code is already written." (কোডটি লেখা আছে)

২.৩ ভার্বের ৪টি ফ্যামিলি (কোনো মুখস্থ ছাড়া চেনার উপায়):

ফ্যামিলি নাম প্যাটার্ন ও সুর উদাহরণ
১. Zero-Change Family বর্তমান, অতীত, V3—সব জায়গায় একই চেহারা। Cut ➔ Cut ➔ Cut
Put ➔ Put ➔ Put
Set ➔ Set ➔ Set
২. The Twin Family V2 এবং V3 হুবহু যমজ ভাই! (একটি শিখলে দুটিই শেষ)। Teach ➔ Taught ➔ Taught
Catch ➔ Caught ➔ Caught
Build ➔ Built ➔ Built
Make ➔ Made ➔ Made
৩. i ➔ a ➔ u Vowel Shift মাঝের ভাওয়েলটি যথাক্রমে i, a, u-তে বদলায়। Sing ➔ Sang ➔ Sung
Begin ➔ Began ➔ Begun
Swim ➔ Swam ➔ Swum
৪. The "-en" Family V3-এর শেষে বাধ্যতামূলকভাবে n বা en যুক্ত হয়। Write ➔ Wrote ➔ Written
Give ➔ Gave ➔ Given
Take ➔ Took ➔ Taken
See ➔ Saw ➔ Seen
Module 3: Prepositions via Mental Physics
Visual Analogies

প্রিপজিশন কোনো নিয়ম মুখস্থের বিষয় নয়—এটি হলো মনের চোখ দিয়ে দেখা ফিজিক্যাল মেটাফর (Visual Physics)।

৩.১ ইন-অন-অ্যাট পিরামিড (In, On, At Pyramid Rule):

প্রিপজিশন স্থানের ক্ষেত্রে (Space) সময়ের ক্ষেত্রে (Time) টেক ও ক্লাসরুম উদাহরণ
IN (সবচেয়ে বড় / ঘেরা) চারপাশ ঘেরা জায়গা, দেশ, ফোল্ডার। বছর, মাস, শতাব্দী (*In 2026, in November*). • "In the computer lab."
• "Save it in this folder."
ON (উপরিভাগ / সারফেস) সমতল তলে লেগে থাকা, স্ক্রিন, টেবিল। বার এবং নির্দিষ্ট তারিখ (*On Monday, on Nov 5*). • "On the whiteboard."
• "The icon is on the screen."
AT (সুনির্দিষ্ট নিশানা) একটি নির্দিষ্ট ঠিকানা বা বিন্দু। ঘড়ির কাঁটার নিখুঁত সময় (*At 9:30 AM*). • "At school."
• "Look at line number 4."

৩.২ বাই বনাম উইথ (BY vs WITH) — কার দ্বারা vs কী দিয়ে:

• BY = The Agent (মানুষ বা কে কাজটি করেছে): "The game was created by Rahul."
• WITH = The Tool (যে যন্ত্র বা সফটওয়্যার দিয়ে করা হয়েছে): "...with Scratch and a mouse."
একত্রে: "The animation was designed by Sarah with a tablet."

৩.৩ শিক্ষকদের ৫টি মারাত্মক প্রিপজিশন ট্র্যাপ (ভুল বনাম সঠিক):

ভুল প্যাটার্ন (যা মুখে চলে আসে) সঠিক স্পোকেন প্যাটার্ন লজিক
❌ "I am good in coding." ✅ "I am good at coding." দক্ষতা বা স্কিল হলো তীর মারার নিশানা (Dartboard 🎯) ➔ AT।
❌ "Please explain me the code." ✅ "Please explain the code to me." তথ্য মুখ থেকে কানের দিকে ছুটে যায় ➔ TO।
❌ "It happened with him." ✅ "It happened to him." কোনো ঘটনা কারো উপর আপতিত হলে ➔ TO।
❌ "Output depends of the code." ✅ "Output depends on the code." কারো ওপর নির্ভর করা ➔ Depend ON।
❌ "Students are interested to learn." ✅ "Students are interested in learning." কোনো বিষয়ে আগ্রহী হওয়া ➔ Interested IN।
Module 4: The SAR Framework for Situations
Spoken Fluency

ভাইভাতে বা ক্লাসে যখনই কোনো সিচুয়েশন ব্যাখ্যা করতে বলা হয়, তখন বাংলায় দীর্ঘ বাক্য চিন্তা করায় মুখ দিয়ে ইংরেজি আসে না। আজ থেকে যেকোনো পরিস্থিতি আপনি বলবেন SAR ফ্রেমওয়ার্কের ৩টি ছোট বাক্যে:

৪.১ বাস্তব ইন্টারভিউ সিমুলেশন (Interview Scenario):

Interviewer: "Masum, how do you handle a student who gives up when code fails?"

// ৩টি শর্ট শটে SAR দিয়ে আপনার উত্তর:
[S - Situation]: "In my Grade 2 class, a student got frustrated because his character fell off the stage."

Module 5: Whiteboard Spelling Hacks
Spelling Confidence

হোয়াইটবোর্ডে লেখার সময় স্পেলিং ফোবিয়া দূর করতে এই ৩টি সুনির্দিষ্ট অর্থোগ্রাফিক রুল মেনে চলুন:

বানানের সুবর্ণ নিয়ম লজিক ও মেকানিক্স বোর্ডের বাস্তব উদাহরণ
১. 1-1-1 CVC Doubling Rule ১টি Syllable + ১টি Vowel + ১টি Consonant থাকলে 'ed' বা 'ing' যোগ করার সময় শেষের অক্ষর ডাবল হবে। • Stop ➔ Stopped / Stopping
• Run ➔ Running
• Plan ➔ Planned
২. Drop the Silent 'E' শব্দের শেষের 'e' যদি অনুচ্চারিত থাকে, তবে 'ing' যোগ করার সময় 'e' মুছে যাবে। • Code ➔ Coding (Codeing ❌)
• Write ➔ Writing (Writeing ❌)
• Create ➔ Creating
৩. The 'Y' Transformation 'y'-এর পূর্বে কনসোনেন্ট থাকলে 'ed' করার সময় 'y' বদলে 'i' হবে। • Try ➔ Tried (Tryed ❌)
• Apply ➔ Applied (Applyed ❌)
৪. Word Chunking Method বড় শব্দকে মুখস্থ না করে সিলেবল অনুযায়ী ৩ টুকরো করে বোর্ডে লিখুন। • Al - go - rithm (Algorithm)
• Se - quen - ce (Sequence)
• Sep - a - rate (মাঝে আছে a rat 🐀)
• To - mor - row (১টি m, ২টি r)

Grammar Architecture

// 60-Second Executive Pitch (চোখে চোখ রেখে, মুখে মৃদু আত্মবিশ্বাসী হাসি দিয়ে):
